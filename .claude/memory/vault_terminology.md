## 术语规范

所有笔记写作遵循 `术语表.md` 中的约定。核心规则：

- **AI 编程助手**（不用「AI 编码助手」「AI Agent」）
- **GitNexus / Serena / Trellis**：正文用品牌大小写，CLI 命令和标签全小写
- **工作流** = 通用 workflow；**工序** = Trellis 的 step-by-step；**SOP** = Code Change Workflow
- 笔记章节统一用 **「## 相关」**和 **「## 来源」**
- **MCP** 全大写（协议名），**MCP Server**（实例），日常可称 **MCP 工具**

**Why:** 同一概念出现多种说法会导致笔记难以检索和关联，AI 写新笔记时也会继承混乱的用词。

**How to apply:** 每次写或改笔记之前，扫一遍 `术语表.md`。遇到新术语需要决策时，先定规范再加到术语表。
